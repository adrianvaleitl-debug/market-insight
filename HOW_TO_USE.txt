MARKET INSIGHT — QUICK START

FIRST INSTALL
1. Extract this ZIP to a folder you want to keep.
2. Open the extracted Market_Insight folder.
3. Double-click SETUP_AND_START.bat.
4. On the first run, required Python packages are installed. Allow a few minutes.
5. Market Insight opens. Later, double-click Start_Market_Insight.vbs.

CONNECT ALPACA LIVE PRICES
1. Create/sign in to your Alpaca account at https://app.alpaca.markets/.
2. In Alpaca, open the API Keys / Market Data area and create an API key pair.
3. Copy the API Key ID and Secret Key. The Secret Key is only shown when created;
   if you lose it, generate a new key pair.
4. Open Market Insight → Settings → Live market data — Alpaca.
5. Paste the API Key ID into the first box and Secret Key into the second box.
6. Click "Save Alpaca keys securely". They are stored in Windows Credential
   Manager, not in the app settings file. The boxes clear after saving.
7. Press "Scan markets now" on Overview.

IMPORTANT ABOUT THE DATA
- Latest available Alpaca IEX trades provide the displayed current price.
- IEX is one US exchange feed, not the full consolidated US market. It may not
  show every trade/venue. Your Alpaca account's data permissions apply.
- Historical indicators (EMA, RSI, MACD, ATR and volume calculations) still use
  Yahoo Finance daily history. Current displayed price and day change use Alpaca
  IEX snapshots when available.
- If keys are missing/rejected or a live snapshot is unavailable, that symbol
  shows a data issue. The app does not silently replace it with delayed prices.
- Snapshots are not continuous streaming or guaranteed tick-by-tick updates.
  Auto-scan repeats at the selected interval (default: 5 minutes).
- Keep your Secret Key private. Never send it to anyone or paste it into chat.

OTHER FEATURES
- Overview: scan your watchlist and see strongest results and caution flags.
- Watchlist: edit up to 100 ticker symbols, separated by commas.
- Settings: Dark mode and automatic scanning are enabled by default.
- Position calculator: illustrative sizing only; it does not place trades.
- TradingView: open a symbol's chart manually if wanted.

The app does not connect to a broker or execute trades. Scores and examples are
educational estimates, not financial advice. Market data can be incomplete.
Keep this folder in the same place after setup.

Getting started

Install it. Set it up. Start researching.

The V2.2 Windows installer includes the latest Market Insight features and handles installation for you. You can also download the portable ZIP if you prefer.

01 / DOWNLOAD

Get the installer

Download the V2.2 Windows installer from the button above.

02 / INSTALL

Follow the prompts

Run the installer and follow the on-screen steps. Launch Market Insight from your Start Menu shortcut.

03 / CONNECT

Connect market data

In Settings → Live market data — Alpaca, enter your API Key ID and Secret Key to enable IEX latest-trade snapshots.

Keep your Secret Key private. Never upload API credentials to GitHub or share them in screenshots. Market Insight stores saved keys in Windows Credential Manager.

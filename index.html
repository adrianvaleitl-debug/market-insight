Meet Market Insight V1.1

The essentials, without the clutter.

A clean, approachable desktop scanner for keeping your watchlist organised, reviewing technical signals and exploring trade risk — all in one workspace.

⌕

Market scanning

Scan a starter universe of US-listed stocks and ETFs, or build your own watchlist of up to 100 symbols.

↗

Technical indicators

Review EMA, RSI, MACD, volume ratio, ATR and recent price changes in one place.

◉

Alpaca IEX snapshots

Use Alpaca credentials for the latest available IEX trade snapshots, with clear errors when data is unavailable.

＋

Risk calculator

Explore illustrative position sizing, stop levels and potential targets. The app does not place trades.

☼

Simple workspace

A desktop layout with Dark and Light appearance options, watchlist controls and automatic scanning.

TradingView links

Open a chart for a symbol when you want to continue your own research.

Getting started

Install it. Set it up. Start researching.

The V1.1 Windows installer handles the app installation for you. You can also download the portable ZIP if you prefer.

01 / DOWNLOAD

Get the installer

Download the V1.1 Windows installer from the button above.

02 / INSTALL

Follow the prompts

Run the installer and follow the on-screen steps. Launch Market Insight from your Start Menu shortcut.

03 / CONNECT

Connect market data

In Settings → Live market data — Alpaca, enter your API Key ID and Secret Key to enable IEX latest-trade snapshots.

Keep your Secret Key private. Never upload API credentials to GitHub or share them in screenshots. Market Insight stores saved keys in Windows Credential Manager.
